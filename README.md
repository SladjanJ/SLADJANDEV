# Sladjan Jeremic — Portfolio

Personal portfolio website showcasing my work as a Web Developer. Built with Next.js, designed for performance, and deployed on Vercel.

**Live site:** [sladjandev.com](https://sladjandev.com/)

---

## Features

- Responsive, mobile-first design
- Hero section with call-to-action
- Featured projects showcase (PlaySlot, Product Classifier, Figma prototypes)
- About me section with stats and social links
- Services overview
- Lead capture section
- Contact form with email delivery (Resend)
- CV download
- Privacy Policy & Terms of Service pages

---

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Resend** (contact form emails)
- **Vercel** (hosting & deployment)
